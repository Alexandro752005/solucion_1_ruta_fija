# Memoria local del proyecto

Esta carpeta mantiene la condición observada del checkout, el objetivo normativo v3.1 y una copia de respaldo fechada. Se actualiza al cerrar cada lote con fecha, rutas, decisiones, bloqueos y evidencia ejecutada; no sustituye el registro fuente.

- [Estado actual](current.md): hechos observados y baseline local.
- [Estado objetivo](target.md): reglas y resultado de producto aprobados.
- `backup/YYYY-MM-DD/`: copia de `current.md` y `target.md` con manifiesto SHA-256.

No guardar claves, tokens, contraseñas, direcciones privadas ni valores de archivos de entorno. Separar siempre código presente, objetivo de producto y verificación ejecutada.
