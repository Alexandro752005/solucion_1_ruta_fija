# Evidencia de migración local V12 → V50

Consultar el [informe operativo](../../operacion/migracion-local-v12-v50-2026-10-23.md). Este directorio contiene exclusivamente evidencias y fuentes sin credenciales: fingerprints, historial Flyway, HTTP, UI del navegador, permisos, inmutables, comandos y respaldos de los documentos actualizados. El dump y las credenciales permanecen fuera de este directorio y excluidos de Git.

`manifest-operacion.sha256` sella estas evidencias, el informe y las cuatro actualizaciones documentales; no modifica los manifiestos históricos ni las actas firmadas. Los logs copiados son cortes temporales. La base normal queda operativa y puede incorporar eventos legítimos después del corte.
