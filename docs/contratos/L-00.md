## Decisión de integración

El registro v3.1 gobierna las reglas. El inventario de código heredado no cambia esa precedencia. Para L-00 se seleccionó provisionalmente Gmail SMTP S/0: la organización controla la cuenta emisora; Google controla gmail.com; la falta de dominio propio se acepta como excepción limitada al piloto. Esta decisión no afirma que la organización controle gmail.com y puede cambiarse de proveedor posteriormente.

La integración de SMTP, carga local de la contraseña de aplicación, comprobación de elegibilidad de la cuenta, aplicación de cuotas y entrega real se reservan a L-01, bajo los límites registrados en docs/evidencia/L-00/decision-Gmail-2026-10-14.md. No se envió correo durante L-00. OPEN-DEVICE-INVENTORY se registra para L-08, no como bloqueo de esta baseline. Offline permanece excluido y su código se trata como deuda de alcance a retirar en L-05 con estrategia para los comandos idempotentes y datos ya almacenados.
